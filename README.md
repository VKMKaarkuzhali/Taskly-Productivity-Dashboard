# ✦ Taskly – Productivity Dashboard

Taskly is a modern and interactive productivity dashboard designed to help users organize their daily tasks, stay focused, and track their progress.

## 🌟 Features

- 📝 Add and manage tasks
- ✅ Mark tasks as completed
- ⭐ Mark important tasks
- 🔍 Search tasks
- 📂 Filter tasks
- 📊 Track task progress
- 🌱 Task priority selection
- 📚 Task category selection
- 🕐 Whole-day task option
- 🔔 Notification interface
- 🌙 Light/Dark theme
- 👤 User profile section
- 🚪 Profile logout option
- ✨ Motivational quotes
- 🎨 Interactive opening screen
- 💾 Task data stored in the browser

## 🎯 Objective

The main objective of Taskly is to provide a simple but visually engaging environment where users can organize their responsibilities and maintain productivity.

Instead of focusing only on task management, Taskly combines task organization with motivational elements to encourage users to complete their daily goals.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- Visual Studio Code
